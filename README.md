## 🐶 PetShop Vue — E-commerce (Refactorizado)

Aplicación web para la venta de alimentos y accesorios para mascotas.

### Problema
Las tiendas de mascotas necesitan mostrar sus productos de forma clara, permitiendo que los usuarios puedan revisar información detallada antes de comprar.

### Solución
Se desarrolló una versión mejor estructurada utilizando **Vue.js**, organizando el proyecto en componentes reutilizables y mejorando la interacción del usuario con el catálogo.

Se priorizó:
- Visualización clara de productos  
- Navegación simple  
- Base escalable  

### Mi rol
- Planificación del proyecto  
- Diseño de la interfaz  
- Desarrollo completo del frontend  
- Refactorización y organización del código  

### Resultados
- Mejor estructura del proyecto  
- Interfaz más clara y ordenada  
- Base preparada para futuras funcionalidades

**Tecnologías:** Vue.js · JavaScript · HTML · CSS · Bootstrap  

Repositorio:  
https://github.com/Tefiita/petShopVue
